\## Установка Ubuntu Server в VirtualBox

Задача: поставить второю VM с Ubuntu Server

Что сделал: создал VM (2 ГБ ОЗУ, 25 ГБ диск), установил через текстовый установщик

Проблемы:

1\. Чёрный экран с мигающим курсором: не нашлась загрузка

2\. У VM был подключён диск Windows (80 ГБ) вместо нового. Откреплён, создан новый VDI 25 ГБ

3\. Установщик "не видит дисков": диск не был подключён к контроллеру SATA

4\. Зелёная черепаха в углу окна VM: Hyper-V замедляет VirtualBox. Отключил Hyper-V через bcdedit

Итог: Ubuntu установлена, вход работает, снимок ubuntu-clean-install сделан
